# BARFI

This repository hosts a cute static webpage for Barfi, a white and furry Maltipoo with a friendly personality.

## About Barfi

Barfi is a sweet Maltipoo pet with a bright, gentle nature and a soft white coat. She is playful, affectionate, and happiest when she is close to her people.

## Website

The site is built as a simple static page using `index.html` and the photo at `assets/barfi.jpg`, so it can be published directly with GitHub Pages.
